CodePulse — a browser-based development IDE

CodePulse brings HTML, CSS and JavaScript editing, templates for multiple languages and an organized workspace together to write and review code directly in the browser.

The IDE includes AI-assisted code correction through OpenAI, Claude and Gemini, with provider settings configured by each user.

Its monorepo architecture connects a web interface to a Node.js backend with code-execution endpoints and an automated testing setup.
