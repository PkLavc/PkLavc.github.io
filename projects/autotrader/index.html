Autotrader

An autonomous market-research system that turns Kronos-base forecasts into a constrained simulated portfolio, executes unattended through GitHub Actions and exposes every decision in a public dashboard.

Open live dashboard View GitHub

Autonomous portfolio research, not a static demo

Autotrader was built to answer a simple engineering question: what happens if a financial foundation model is allowed to scan a fixed liquid universe, rank its own forecasts, construct a portfolio under hard risk limits and repeat that process automatically over time?

20market assets scanned
5maximum positions
18%max weight per asset
10%minimum cash buffer

Decision pipeline

Each scheduled run pulls fresh daily market data, generates a five-session Kronos forecast for every supported asset, ranks expected returns and rebalances a simulated account while preserving cash and position limits.

1. Market dataDaily OHLCV history
2. Kronos-base5-session forecast
3. RankingExpected-return score
4. PortfolioRisk-constrained targets
5. RecordTrades + equity history

Architecture and safeguards

The project deliberately separates model inference from repository write permissions. Upstream Kronos updates are pinned and tested before adoption, while portfolio state is persisted only after a successful simulation run.

Kronos-base102.3M-parameter financial foundation model used as the forecasting engine.
Python + PyTorchCPU inference, market-data processing, ranking, portfolio construction and simulation.
GitHub ActionsScheduled execution, tests, state persistence and autonomous operation.
Safe upstream syncNew Kronos revisions are adopted only after regression and compatibility tests pass.
Public dashboardEquity curve, bullish/bearish forecast bars, allocation and complete execution log.
Paper executionSimulated fills include slippage and preserve a reproducible history before any live-broker integration.

Public experiment

The dashboard keeps the experiment observable: portfolio value over time, positive and negative model forecasts, current allocation and a timestamped table of simulated buys and sells.

Autotrader currently uses simulated capital. The live dashboard is a research record, not financial advice and not evidence of future returns.
