Omnichannel

A portable customer-service platform where specialist AI agents share a controlled conversation while knowledge, customers, credentials and history remain isolated per company.

View source on GitHubExplore architecture

Specialist agents

Commercial, technical support, warranty and service agents operate under one orchestrator instead of one oversized prompt.

Scoped knowledge

RAG documents, quick replies and operational rules are selected by tenant and channel, preventing knowledge from crossing companies.

Human operation

Chatwoot centralizes conversations, contact data, cards, assignment and accountable human handoff.

Architecture

Channels → AI Gateway → Orchestrator → Specialist agent → RAG and tools → Chatwoot / human

The TypeScript gateway owns tenant resolution, message policy, tool calls and persistence. PostgreSQL with pgvector stores operational records and embeddings; Redis supports runtime coordination; Chatwoot provides the agent workspace; n8n is available for external workflows.

Designed for real service operations

  • Conversation imports are resumable and preserve source/channel identity.
  • Customer cards accumulate name, phone, device, requested service, unit and handoff status.
  • Knowledge content is inspectable, editable, exportable and versioned.
  • Prompt changes and learning candidates follow approval and audit flows.
  • Public access can be online while the local host is active and becomes a neutral offline page when it is not.

Portable without leaking private data

The public repository contains only application code and fictitious examples. Deployment data belongs to a separate omnichannel-data directory: databases, customers, conversations, RAG sources, cards, environment secrets and backups never need to enter Git history.

Manual operation by design

The application does not install scheduled tasks or startup entries. On Windows the operator starts it explicitly through Omnichannel.bat; without that manual action, the platform and its public tunnels remain stopped.
