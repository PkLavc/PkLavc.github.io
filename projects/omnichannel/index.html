Omnichannel

Omnichannel is a self-hosted customer-service platform that connects Chatwoot to a gateway of specialist AI agents. It keeps identity, prompts, RAG knowledge, conversations, contacts, service cards, and business integrations isolated per tenant.

ChannelsWhatsApp, Instagram, Facebook, website and API inboxes through Chatwoot
OrchestrationCoordinator and specialist agents for commercial, support and post-sale work
KnowledgeEditable RAG documents, rules, quick replies and historical conversations
PersistencePostgreSQL plus a separate portable private-data directory
OperationsHuman handoff, customer context, service cards and audit trails
DeploymentDocker Compose with a stable Cloudflare access layer

System Architecture

The public access layer remains stable while the operational services can move between authorized computers. A gateway identifies the tenant and channel, retrieves only that tenant’s context, delegates to the appropriate specialist, and sends the response back through Chatwoot.

Customer channel → Chatwoot → AI Gateway → Coordinator → Specialist agent
Tenant RAG + rules → Customer and service context → Response or human handoff

Tenant Isolation and Portability

  • The public repository contains the reusable system and no preconfigured company identity.
  • Each tenant has its own prompts, rules, channels, RAG, conversations, contacts and cards.
  • Provider credentials can be global while their allowed tenant scope remains explicit.
  • The private-data directory can be exported, backed up and restored independently of the application source.

Operational Model

The stack starts only through an explicit operator action. While the backend is online, authorized users can reach the stable web entry point; when it is unavailable, the public page shows a neutral service status. No automatic Windows startup is required.
