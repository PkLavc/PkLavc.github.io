AWS Transforma ahora Automatiza la conversión de código nativo de Azure-to-AWS

AWS Transform introduce una nueva capacidad para la conversión automatizada del código de aplicación Azure Cloud-native .NET a AWS SDK, simplificando las migraciones cruzadas.

Publicado el 17 de octubre de 20261 min de lecturaplataformas de nubes

Datos confirmados

El 16 de octubre de 2026, AWS anunció la disponibilidad general de la conversión de códigos de Azure-to-AWS SDK en AWS Transform, una característica diseñada para automatizar la migración de Microsoft Azure cloud-native .NET a AWS.

El servicio identifica código de servicio Azure dentro del código fuente presentado .NET y lo convierte en llamadas AWS SDK equivalentes, validando que los cambios se incorporan en la salida transformada.

AWS Transform está disponible en ocho regiones de AWS: el este de Estados Unidos (N. Virginia), Asia Pacífico (Mumbai, Tokio, Seúl, Sydney), Canadá (Central), y Europa (Frankfurt, Londres).

El soporte de conversión incluye Funciones Azure a AWS Lambda, Almacenamiento de Blob Azure a Amazon S3, y almacenamiento de cola Azure a Amazon SQS. Azure Cosmos DB a Amazon DynamoDB conversión está disponible en estado de vista previa.

Análisis técnico

La característica funciona a través de una fase de evaluación donde AWS Transform descubre el uso de Azure SDK en la base de códigos presentada, presentando opciones de conversión tanto en un informe de evaluación como en un plan de modernización. Los desarrolladores pueden aceptar estas opciones o modificarlas antes de la ejecución.

Este enfoque aborda un importante desafío de ingeniería en la modernización de aplicaciones de tapa cruzada mediante la automatización de lo que anteriormente era refactoring manual. La capacidad del servicio para traducir llamadas de servicio entre proveedores de nube reduce la complejidad de la migración para aplicaciones .NET aprovechando servicios de almacenamiento y sin servidor.

La disponibilidad regional en ocho regiones de AWS sugiere que el servicio está diseñado para uso global de las empresas, aunque el anuncio no revela requisitos de procesamiento, manejo de residencia de datos o métricas de precisión de transformación. El estado de vista previa de la conversión de Cosmos DB a DynamoDB indica el refinamiento continuo de esa asignación específica.

  • Conversiones compatibles: Funciones de Azure → AWS Lambda, Azure Blob Almacenamiento → Amazon S3, Azure Queue Storage → Amazon SQS
  • Cosmos DB a DynamoDB conversión está en vista previa
  • Servicio requiere .NET código fuente de aplicación para el análisis
