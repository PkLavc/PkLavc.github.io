AWS EC2 M9gd instancias con procesadores Graviton5 y Nitro Isolation Engine ahora disponible, soportando la IA agente y seguridad en la nube matemáticamente probada

AWS lanza instancias M9gd EC2 con procesadores Graviton5 y el innovador Nitro Isolation Engine, ofreciendo un rendimiento mejorado para las cargas de trabajo de IA y un nuevo nivel de seguridad en la nube matemáticamente comprobada.

Publicado 26 de noviembre de 20264 min leerplataformas de nubes

Datos confirmados

Hasta el 25 de noviembre de 2026, las instancias de Amazon EC2 M9gd están disponibles en la región de Asia Pacífico (Seúl). Estos casos son impulsados por procesadores AWS Graviton5, que representan la quinta generación de CPUs diseñadas a medida de AWS.

Los procesadores Graviton5 ofrecen un rendimiento máximo del 25% en comparación con las instancias M8gd basadas en AWS Graviton4. Las mejoras específicas de rendimiento incluyen ser hasta un 30% más rápido para bases de datos, hasta un 35% más rápido para aplicaciones web, y hasta un 35% más rápido para el aprendizaje automático.

Las instancias M9gd se construyen en el sistema Nitro AWS de sexta generación y son las primeras en incorporar el motor de aislamiento Nitro. Este motor utiliza la verificación formal para proporcionar seguridad matemática de que las cargas de trabajo de los clientes están aisladas entre sí y de los operadores de AWS. Este enfoque es declarado para pionero un nuevo estándar para la seguridad de la nube matemáticamente probada.

Estos casos están diseñados para un amplio espectro de cargas de trabajo para fines generales, incluyendo servidores de aplicaciones, microservicios, juegos, caché y contenedores. También proporcionan el rendimiento requerido para los casos de uso de IA, como el razonamiento en tiempo real, la generación de códigos y la orquestación de varios pasos.

Las instancias M9gd incluyen almacenamiento local de nivel de bloque SSD basado en NVMe. Este almacenamiento está destinado a cargas de trabajo que requieren acceso local de baja velocidad para fines como el espacio de rasguños, archivos temporales y caches.

Los clientes pueden comprar instancias M9gd en la región de Asia Pacífico (Seúl) a través de varias opciones, incluyendo Planes de Ahorro, On-Demand, Spot Instances, Dedicated Instances, o Hosts Dedicados.

Análisis técnico

La introducción de las instancias Amazon EC2 M9gd marca una notable evolución en las ofertas de cálculo de AWS, integrando el procesador Graviton5 y el motor Nitro Isolation. Esta combinación aborda tanto las demandas de rendimiento en una gama de cargas de trabajo como las preocupaciones fundamentales en materia de seguridad dentro de entornos de nube de múltiples componentes. Para los ingenieros de software, estos avances se traducen en implicaciones directas para el diseño de aplicaciones, estrategias de despliegue y posturas de seguridad.

Las mejoras de rendimiento de los procesadores Graviton5, con un rendimiento máximo de hasta un 25% en comparación con Graviton4, proporcionan un camino claro para optimizar las ratios de rentabilidad. Las ganancias específicas —hasta un 30% más rápido para bases de datos, un 35% más rápido para aplicaciones web y un 35% más rápido para el aprendizaje automático— indican mejoras arquitectónicas específicas dentro del diseño Graviton5. Para los administradores y desarrolladores de bases de datos, esto podría significar mayor rendimiento de transacción o menor latencia de consultas sin requerir una arquitectura de escala. Los desarrolladores de aplicaciones web pueden observar mejores tiempos de respuesta y mayor capacidad de usuario simultánea. En contextos de aprendizaje automático, en particular para las etapas de procesamiento de datos o de preprocesamiento de datos que están sujetas a CPU, la aceleración del 35% puede reducir directamente los tiempos de procesamiento y los costos operativos. Estas mejoras son importantes para las cargas de trabajo que se benefician de una CPU equilibrada, memoria y perfil de red, característica de la familia de instancias M.

El Nitro Isolation Engine representa un cambio significativo en las garantías de seguridad en la nube. Mediante la verificación formal, el AWS tiene como objetivo ofrecer garantías matemáticas del aislamiento de la carga de trabajo. Las medidas tradicionales de seguridad a menudo dependen de pruebas extensas, auditorías y pruebas de penetración, que pueden identificar vulnerabilidades pero no prueban matemáticamente la ausencia de ciertas clases de fallas. La verificación formal, aplicada a nivel de hipervisor dentro del Sistema Nitro, ofrece un mayor grado de confianza en que las cargas de trabajo de los clientes están realmente aisladas entre sí y de los operadores de AWS. Esto tiene profundas implicaciones para industrias altamente reguladas, como finanzas, salud o gobierno, donde requisitos estrictos de cumplimiento exigen un aislamiento verificable. Los ingenieros que utilizan aplicaciones sensibles pueden aprovechar esta garantía para cumplir los objetivos de cumplimiento y aumentar la confianza en la infraestructura subyacente, lo que podría simplificar las auditorías de seguridad y las evaluaciones de riesgos. La reducción de la superficie de ataque mediante mecanismos de aislamiento formalmente verificados a nivel de hipervisor es una consecuencia de ingeniería directa, ya que minimiza las vías de acceso o interferencia no autorizados.

Cabe destacar la mención explícita de instancias M9gd que apoyan "casos de uso de AI en tiempo real, generación de códigos y orquestación de varios pasos. Las cargas de trabajo de IA a menudo implican procesamiento iterativo, toma de decisiones e interacción con diversas fuentes de datos o API. Estas tareas pueden ser computacionalmente intensivas, lo que requiere un rendimiento eficiente de la CPU y un acceso de baja latencia a los datos. El aumento de rendimiento del Graviton5, especialmente para el aprendizaje automático, contribuye directamente a la eficiencia de estos agentes de IA. Además, la seguridad mejorada proporcionada por el Nitro Isolation Engine es fundamental para la AI, ya que estos sistemas pueden manejar datos sensibles, ejecutar lógica compleja o interactuar con sistemas de negocio críticos. Asegurar que el entorno de ejecución de un agente de inteligencia artificial esté matemáticamente aislado de otros inquilinos o amenazas potenciales internas pueden mitigar los riesgos asociados con fugas de datos, acceso no autorizado o manipulación del comportamiento del agente. El almacenamiento local de NVMe SSD también soporta estos casos de uso proporcionando espacio de rasguño de alta velocidad para archivos temporales, pasos de razonamiento intermedio, o caché a menudo accedido a modelos o datos, que pueden ser cruciales para mantener el rendimiento en tiempo real en flujos de trabajo agentes.

La inclusión de almacenamiento local de SSD basado en NVMe ofrece beneficios prácticos para una variedad de aplicaciones. Para bases de datos, esto puede acelerar las operaciones con tablas temporales, registros de transacciones o índices de acceso frecuente. Las aplicaciones web pueden aprovechar esto para datos de sesión, almacenamiento de caché o almacenamiento temporal de archivos, mejorando la capacidad de respuesta. Para el cálculo de uso general, el almacenamiento local de alta velocidad y baja latencia puede mejorar significativamente el rendimiento de las aplicaciones que generan o procesan grandes cantidades de datos temporales, reduciendo la dependencia del almacenamiento adjunto de la red para operaciones transitorias. Esta opción de diseño permite a los desarrolladores optimizar los componentes intensivos de I/O de sus aplicaciones mediante la colocación de datos temporales en el almacenamiento más rápido disponible, afectando directamente el rendimiento de aplicaciones y la latencia.
