AWS lanza EC2 T9g Instances con procesadores Graviton5, Ofreciendo un 45% mejor rendimiento

AWS presenta sus nuevas instancias Amazon EC2 T9g, con el procesador Graviton5 y el sistema Nitro, prometiendo mejoras sustanciales en el rendimiento de los precios y una mayor seguridad para una amplia gama de cargas de trabajo en la nube.

Publicado 20 de noviembre de 20264 min leercloud-platforms, chips-y-computing-hardware

Datos confirmados

AWS ha anunciado la disponibilidad general de nuevas instancias Amazon EC2 T9g, efectiva hoy, 2026-11-20. Estos casos son alimentados por procesadores AWS Graviton5 y se construyen en las últimas tarjetas AWS Nitro de sexta generación. Las instancias T9g están diseñadas para cargas de trabajo que requieren una utilización de CPU baja a moderada.

En comparación con las instancias T4g de la generación anterior, las instancias T9g ofrecen hasta un 45% mejor rendimiento de precios. Mejoras específicas de rendimiento incluyen hasta 2.3x el rendimiento de compute, ancho de banda de red superior 1,5x y ancho de banda de EBS 2.8x superior. Las nuevas instancias están disponibles en tamaños nano, micro, pequeño y mediano.

Las instancias T9g cuentan con el Nitro Isolation Engine, que utiliza la verificación formal para proporcionar seguridad matemática de que las cargas de trabajo de los clientes están aisladas entre sí y de los operadores de AWS. Esto se presenta como un nuevo estándar para la seguridad de la nube matemáticamente comprobada. Las instancias utilizan el mismo sistema de crédito de CPU como T4g, soportando tanto modos Estándares como ilimitados.

Las cargas de trabajo para casos de T9g incluyen procesamiento de datos, portales de inicio de sesión, bases de datos pequeñas, microservicios, sitios web de bajo tráfico, servicios de freemium, entornos de estadificación y desarrollo, y tareas de computación de corta duración como procesamiento por lotes, funciones impulsadas por eventos y tuberías CI/CD. T9g.micro y T9g.small instancias están disponibles bajo el AWS Free Tier.

Estas instancias están disponibles en varias regiones del AWS: el este de Estados Unidos (N. Virginia, Ohio), el oeste de Estados Unidos (N. California, Oregon), Canadá (Central), Sudamérica (São Paulo), Europa (Frankfurt, España) y Asia Pacífico (Malasia, Singapur, Sydney, Tokio). Los clientes pueden comprar instancias de T9g a través de planes de ahorros, instancias en ejecución y casos Spot.

Análisis técnico

La introducción de las instancias de Amazon EC2 T9g representa una evolución significativa en las ofertas de instancias irrumpidas de AWS, aprovechando los últimos procesadores Graviton5 y avances en el Sistema Nitro AWS. Los casos de T-series están diseñados fundamentalmente para aplicaciones que no requieren una utilización consistentemente alta de CPU, pero pueden experimentar picos ocasionales. El sistema de crédito de la CPU, que permite a los casos acumular créditos durante períodos de bajo uso y gastarlos durante ráfagas, sigue siendo un modelo operativo básico para T9g, asegurando un rendimiento previsible dentro de este patrón de uso. Este modelo es particularmente eficaz para entornos de desarrollo, servidores web de pequeña escala y ciertas tareas de procesamiento de datos donde el uso promedio de CPU es bajo.

El salto generacional a los procesadores Graviton5 es un factor clave detrás de las mejoras de rendimiento establecidas. Si bien no se divulgaron detalles arquitectónicos específicos de Graviton5, los aumentos reportados —hasta un rendimiento de computación de 2.3x, ancho de banda de red 1.5x y ancho de banda de 2,8x EBS en comparación con T4g— indican avances sustanciales en las capacidades de procesamiento de núcleo y I/O. Para los ingenieros de software, esto se traduce directamente en una ejecución más rápida de tareas compute-bound, reducción de latencia para microservicios intensivos en red, y acceso de datos más rápido para aplicaciones que dependen de Amazon EBS. Esto puede dar lugar a aplicaciones más receptivas y un procesamiento más eficiente de las cargas de trabajo de ráfagas, incluso dentro del modelo basado en T-series. Las aplicaciones compiladas para la arquitectura de ARM se beneficiarán directamente de estas mejoras de procesador, reforzando la tendencia hacia despliegues de nubes nativas de ARM.

Las instancias T9g se construyen sobre las "tarjetas más antiguas de sexta generación AWS Nitro", lo que significa el desarrollo continuo del Sistema Nitro AWS. El sistema Nitro descarga funciones de virtualización, almacenamiento y networking desde la CPU host a hardware dedicado, lo que contribuye a mejorar el rendimiento, la seguridad y la eficiencia. La actualización a una tarjeta Nitro de sexta generación sugiere otras optimizaciones en estas áreas, apoyando directamente el aumento de la red y el ancho de banda EBS observado en instancias T9g. Esta integración hardware-software es fundamental para ofrecer un rendimiento constante y mantener las garantías de aislamiento que son fundamentales para la seguridad en la nube.

Una mejora notable es la inclusión del Nitro Isolation Engine, que emplea la verificación formal para proporcionar "seguridad nublada demostrada matemáticamente". La verificación formal es un método riguroso de probar la exactitud de los diseños de hardware o software utilizando técnicas matemáticas. En el contexto de la infraestructura de la nube, la aplicación de la verificación formal al Nitro Isolation Engine significa que los mecanismos responsables de aislar las cargas de trabajo de los clientes entre sí y de los operadores de AWS se han demostrado matemáticamente para funcionar como se pretendía, sin interacciones o vulnerabilidades no deseadas. Esto establece una barra más alta para la seguridad, pasando de las pruebas tradicionales y la auditoría a una garantía más determinista del aislamiento. Para los desarrolladores y organizaciones, esto puede simplificar los esfuerzos de cumplimiento y aumentar la confianza en la postura de seguridad de sus aplicaciones que se ejecutan en casos de T9g, en particular para cargas de trabajo sensibles.

Desde una perspectiva de ingeniería práctica, el 45% mejor rendimiento de precios ofrece oportunidades significativas para la optimización de costos. Para los usuarios actuales de T4g, la actualización a instancias T9g puede producir ahorros de costos inmediatos para el mismo nivel de rendimiento, o permitir un mayor rendimiento dentro del mismo presupuesto. Para nuevos proyectos o migraciones, las instancias T9g proporcionan un punto de entrada más económico para una amplia gama de cargas de trabajo livianas. La inclusión de T9g.micro y T9g.small en el AWS Free Tier reduce aún más la barrera a la entrada, permitiendo a los desarrolladores experimentar con Graviton5 y el Sistema Nitro sin incurrir en costos inmediatos, fomentando una adopción más amplia e innovación. La red mejorada y el ancho de banda EBS también significa que las aplicaciones que anteriormente estaban ligadas a las series T podrían ahora realizar de manera más eficiente, lo que podría reducir la necesidad de escalar hasta tipos de instancias de alto rendimiento más costosos y continuos para ciertos patrones de I/O. Sin embargo, es fundamental que los ingenieros evalúen sus perfiles específicos de carga de trabajo para asegurar que los casos T9g, con su modelo de CPU irrumpido, sean la elección adecuada, ya que no están diseñados para una utilización sostenida de alta CPU.
