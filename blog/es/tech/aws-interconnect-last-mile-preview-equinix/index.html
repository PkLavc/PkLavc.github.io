Interconexión AWS - Vista previa de última milla con Equinix: simplificación y seguridad de la conectividad de la nube híbrida

AWS presenta una vista previa de Interconnect - última milla con Equinix, ofreciendo conexiones privadas simplificadas, seguras y resilientes a AWS, con encriptación MACsec y alta disponibilidad.

Publicado el 4 de noviembre de 20264 min leerPlataformas Cloud

Datos confirmados

Interconexión AWS - la última milla está disponible en vista previa con Equinix, permitiendo a los usuarios conectar su infraestructura a través de la red global de 282 centros de datos de Equinix a AWS. Este servicio proporciona conexiones gestionadas, privadas y resilientes a AWS, eliminando la necesidad de que los clientes pidan conexiones cruzadas o configuren routers.

La configuración se realiza a través de la consola de administración AWS, donde los usuarios seleccionan una región AWS, velocidad de ancho de banda, una puerta de conexión directa y su ID de proyecto Equinix Fabric One. AWS genera entonces una clave de activación, que se introduce en el portal Equinix Fabric One para finalizar la conexión. Las conexiones también se pueden iniciar desde el portal Equinix Fabric One.

AWS and Equinix pre-provision quad-redundant capacity, distributed across two physical locations and four distinct links. Esta configuración incluye pares BGP preconfigurados, VLANs y ASNs. El servicio viene con un 99.99% de disponibilidad SLA.

El tráfico entre dispositivos AWS y Equinix edge se cifra por defecto utilizando MACsec (Media Access Control Security).

Durante la fase de vista previa, 1 Gbps Interconnect - las conexiones de última milla están disponibles sin cargo. Estas conexiones se ofrecen a la Región Oeste de los Estados Unidos (N. California) a través del metro de San José y a la Región Este de los Estados Unidos (N. Virginia) a través del metro norte de Virginia.

Con disponibilidad general, el servicio apoyará el escalado de ancho de banda desde 1 Gbps hasta 100 Gbps. Las conexiones se pueden crear utilizando la consola de gestión AWS, la interfaz de línea de comandos AWS (CLI) o la API AWS. El GitHub dispone de un paquete de API abierto para la integración de socios, y se proporciona documentación completa para AWS Interconnect - última milla.

El anuncio fue hecho el 4 de noviembre de 2026.

Análisis técnico

El establecimiento de una conectividad de nube híbrida segura, de alto rendimiento y resiliente ha presentado históricamente importantes desafíos de ingeniería. Los enfoques tradicionales suelen implicar procesos manuales complejos para ordenar conexiones físicas, configurar dispositivos de red y gestionar protocolos de enrutamiento. Estas tareas exigen conocimientos especializados en redes, introducen el potencial de error humano y pueden dar lugar a tiempos prolongados de provisión. La Interconexión AWS - vista previa de última milla con Equinix aborda directamente estas complejidades operativas ofreciendo un servicio gestionado que abstrae gran parte de la configuración de red física y lógica subyacente.

La propuesta de valor básico del servicio para ingenieros de software y arquitectos de red reside en su simplificación operacional. Al permitir la configuración de conexión a través del portal AWS Management Console o Equinix Fabric One, y configurar automáticamente BGP peering, VLANs y ASNs, el servicio reduce significativamente el esfuerzo manual y el conocimiento especializado requerido. Este cambio de un modelo de provisión manual centrado en hardware a un enfoque definido por software, basado en API se alinea con los principios modernos de ingeniería en la nube. Los ingenieros pueden proporcionar conexiones privadas con unos pocos clics, descargando la carga de configuración de infraestructura física y configuración compleja de red a AWS y Equinix. Esta automatización puede acelerar el despliegue de arquitecturas de nubes híbridas, permitiendo que los equipos de desarrollo se centren en la lógica de aplicaciones en lugar de la plomería de red.

La seguridad es una preocupación fundamental para el despliegue de nubes híbridas, especialmente para el intercambio de datos sensibles entre entornos locales y la nube. La inclusión de la encriptación MACsec por defecto para el tráfico entre los dispositivos AWS y Equinix edge es una mejora notable. MACsec opera en Layer 2 (la capa de enlace de datos) del modelo OSI, proporcionando cifrado de hop-by-hop y cheques de integridad de datos. Esta encriptación de capas físicas ofrece una base de seguridad robusta, protegiendo datos en tránsito de escuchas y manipulación antes de que alcance mecanismos de encriptación de capas superiores. Para las organizaciones con estrictos requisitos de cumplimiento o aquellos que manejan información altamente confidencial, este cifrado predeterminado de MACsec proporciona una capa adicional de seguridad sin requerir configuración explícita por el usuario, simplificando la postura de seguridad de la conexión híbrida.

El diseño para la resiliencia y la disponibilidad es otro aspecto técnico clave. La capacidad de excavación de cuádruples preprovisionada, distribuida en dos lugares y cuatro enlaces separados, está diseñada para minimizar puntos de fracaso únicos. Esta arquitectura, combinada con la disponibilidad del 99,99% SLA, proporciona una base para aplicaciones altamente disponibles que abarcan entornos locales y AWS. Para las cargas de trabajo críticas de las misiones, es esencial este nivel de redundancia, asegurando un funcionamiento continuo incluso en caso de fallos de componentes o de interrupciones localizadas. La configuración automatizada de esta redundancia compleja reduce aún más la sobrecarga de ingeniería, ya que los equipos no necesitan diseñar, implementar y validar una topología de red tan resiliente ellos mismos.

La disponibilidad de un paquete de API abierto en GitHub para la integración de socios indica un avance estratégico hacia la promoción de un ecosistema alrededor de AWS Interconnect - último kilómetro. Esto permite a proveedores externos y proveedores de servicios construir integraciones, lo que podría ampliar el alcance y las capacidades del servicio. Para los desarrolladores, la capacidad de crear conexiones utilizando el AWS CLI o API significa que el suministro puede integrarse en los flujos de trabajo existentes de infraestructura como código y los sistemas automatizados de implementación. Este control programático es fundamental para despliegues de cloud híbridos escalables y repetibles, permitiendo una configuración coherente y reduciendo la intervención manual.

Durante la vista previa, el servicio se limita a 1 conexiones Gbps y regiones específicas de EE.UU. (N. California y N. Virginia). Si bien este ancho de banda inicial y alcance regional son adecuados para la evaluación y los despliegues iniciales, el plan confirmado para escalar ancho de banda de 1 Gbps a 100 Gbps sobre disponibilidad general aborda las necesidades de cargas de trabajo de alto rendimiento y grandes empresas. El período de previsualización sin costo ofrece una oportunidad práctica para que los equipos de ingeniería evalúen el rendimiento del servicio, las capacidades de integración y los beneficios operacionales dentro de sus configuraciones de nube híbrida existentes antes de comprometerse a una adopción más amplia. La documentación para AWS Interconnect - última milla será un recurso crítico para que los ingenieros entiendan los procedimientos operativos detallados, patrones de integración y mejores prácticas para aprovechar esta nueva opción de conectividad.
