AWS Transform agora automatiza a conversão de código nativo da nuvem de Azure para AWS

AWS Transform introduz uma nova capacidade de conversão automática do código de aplicação .NET nativo de nuvem Azure para AWS SDK, simplificando migrações de nuvens cruzadas.

Publicado em 17 de outubro de 20261 min de leituraPlataformas de nuvem

Fatos confirmados.

Em 16 de outubro de 2026, AWS anunciou a disponibilidade geral de conversão de código Azure-to-AWS SDK em AWS Transform, um recurso projetado para automatizar a migração de aplicativos Microsoft Azure nativo de nuvem para AWS.

O serviço identifica o código de serviço Azure dentro do código fonte .NET enviado e converte-o em chamadas AWS SDK equivalentes, validando que as mudanças são incorporadas à saída transformada.

AWS Transform está disponível em oito regiões da AWS: Leste dos EUA (N. Virginia), Pacífico Asiático (Mumbai, Tóquio, Seul, Sydney), Canadá (Centro) e Europa (Frankfurt, Londres).

O suporte de conversão inclui funções Azure para AWS Lambda, armazenamento Azure Blob para Amazon S3 e armazenamento Azure Fila para Amazon SQS. Azure Cosmos DB para Amazon DynamoDB conversão está disponível em status de visualização.

Análise técnica

O recurso opera através de uma fase de avaliação onde a AWS Transform descobre o uso do Azure SDK na base de códigos apresentada, apresentando opções de conversão em um relatório de avaliação e plano de modernização. Os desenvolvedores podem aceitar essas opções ou modificá-las antes da execução.

Esta abordagem aborda um desafio de engenharia significativo na modernização de aplicações de nuvens cruzadas automatizando o que antes era refatoramento manual de código. A capacidade do serviço de traduzir chamadas de serviço entre provedores de nuvem reduz a complexidade de migração para aplicativos .NET alavancando serviços de servidor e armazenamento.

A disponibilidade regional em oito regiões da AWS sugere que o serviço é projetado para uso empresarial global, embora o anúncio não revele requisitos de processamento, tratamento de residência de dados, ou métricas de precisão de transformação. O status de visualização da conversão de Cosmos DB para DynamoDB indica o refinamento contínuo desse mapeamento específico.

  • Conversões suportadas: Funções Azure → AWS Lambda, Armazenamento Azure Blob → Amazon S3, Armazenamento Azure Fila → Amazon SQS
  • Cosmos DB para DynamoDB conversão está em pré-visualização
  • Serviço requer submissão de código fonte para análise.
