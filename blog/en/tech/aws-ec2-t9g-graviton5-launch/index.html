AWS Launches EC2 T9g Instances with Graviton5 Processors, Offering 45% Better Price Performance

AWS introduces its new Amazon EC2 T9g instances, featuring the Graviton5 processor and Nitro System, promising substantial price-performance improvements and enhanced security for a wide range of cloud workloads.

Published November 20, 20264 min readcloud-platforms, chips-and-computing-hardware

Confirmed facts

AWS has announced the general availability of new Amazon EC2 T9g instances, effective today, 2026-11-20. These instances are powered by AWS Graviton5 processors and are built on the latest sixth-generation AWS Nitro cards. The T9g instances are designed for workloads requiring low to moderate CPU utilization.

Compared to the previous generation T4g instances, T9g instances deliver up to 45% better price performance. Specific performance improvements include up to 2.3x the compute performance, 1.5x higher network bandwidth, and 2.8x higher EBS bandwidth. The new instances are available in nano, micro, small, and medium sizes.

T9g instances feature the Nitro Isolation Engine, which utilizes formal verification to provide mathematical assurance that customer workloads are isolated from each other and from AWS operators. This is presented as a new standard for mathematically proven cloud security. The instances use the same CPU credit system as T4g, supporting both Standard and Unlimited modes.

Target workloads for T9g instances include data processing, login gateways, small databases, microservices, low-traffic websites, freemium services, staging and development environments, and short-duration compute tasks such as batch processing, event-driven functions, and CI/CD pipelines. T9g.micro and T9g.small instances are available under the AWS Free Tier.

These instances are available in several AWS regions: US East (N. Virginia, Ohio), US West (N. California, Oregon), Canada (Central), South America (São Paulo), Europe (Frankfurt, Spain), and Asia Pacific (Malaysia, Singapore, Sydney, Tokyo). Customers can purchase T9g instances via Savings Plans, On-Demand instances, and Spot instances.

Technical analysis

The introduction of Amazon EC2 T9g instances represents a significant evolution in AWS's burstable instance offerings, leveraging the latest Graviton5 processors and advancements in the AWS Nitro System. T-series instances are fundamentally designed for applications that do not require consistently high CPU utilization but may experience occasional spikes. The CPU credit system, which allows instances to accumulate credits during periods of low usage and spend them during bursts, remains a core operational model for T9g, ensuring predictable performance within this usage pattern. This model is particularly effective for development environments, small-scale web servers, and certain data processing tasks where average CPU usage is low.

The generational leap to Graviton5 processors is a key driver behind the stated performance improvements. While specific architectural details of Graviton5 were not disclosed, the reported increases—up to 2.3x compute performance, 1.5x network bandwidth, and 2.8x EBS bandwidth compared to T4g—indicate substantial advancements in core processing capabilities and I/O throughput. For software engineers, this translates directly into faster execution of compute-bound tasks, reduced latency for network-intensive microservices, and quicker data access for applications relying on Amazon EBS. This can lead to more responsive applications and more efficient processing of burst workloads, even within the T-series' credit-based model. Applications compiled for ARM architecture will directly benefit from these processor enhancements, reinforcing the trend towards ARM-native cloud deployments.

The T9g instances are built on the "latest sixth-generation AWS Nitro cards," signifying continuous development of the AWS Nitro System. The Nitro System offloads virtualization, storage, and networking functions from the host CPU to dedicated hardware, which contributes to improved performance, security, and efficiency. The upgrade to a sixth-generation Nitro card suggests further optimizations in these areas, directly supporting the increased network and EBS bandwidth observed in T9g instances. This hardware-software integration is critical for delivering consistent performance and maintaining the isolation guarantees that are foundational to cloud security.

A notable enhancement is the inclusion of the Nitro Isolation Engine, which employs formal verification to provide "mathematically proven cloud security." Formal verification is a rigorous method of proving the correctness of hardware or software designs using mathematical techniques. In the context of cloud infrastructure, applying formal verification to the Nitro Isolation Engine means that the mechanisms responsible for isolating customer workloads from each other and from AWS operators have been mathematically proven to function as intended, without unintended interactions or vulnerabilities. This sets a higher bar for security assurance, moving beyond traditional testing and auditing to a more deterministic guarantee of isolation. For developers and organizations, this can simplify compliance efforts and increase confidence in the security posture of their applications running on T9g instances, particularly for sensitive workloads.

From a practical engineering perspective, the 45% better price performance offers significant opportunities for cost optimization. For existing T4g users, upgrading to T9g instances can yield immediate cost savings for the same level of performance, or enable higher performance within the same budget. For new projects or migrations, T9g instances provide a more cost-effective entry point for a wide range of lightweight workloads. The inclusion of T9g.micro and T9g.small in the AWS Free Tier further lowers the barrier to entry, allowing developers to experiment with Graviton5 and the Nitro System without incurring immediate costs, fostering broader adoption and innovation. The improved network and EBS bandwidth also means that applications that were previously I/O bound on T-series instances might now perform more efficiently, potentially reducing the need to scale up to more expensive, continuously high-performance instance types for certain bursty I/O patterns. However, it is crucial for engineers to evaluate their specific workload profiles to ensure T9g instances, with their burstable CPU model, are the appropriate choice, as they are not designed for sustained high CPU utilization.
