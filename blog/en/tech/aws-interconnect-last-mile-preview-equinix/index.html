AWS Interconnect - Last Mile Preview with Equinix: Simplifying and Securing Hybrid Cloud Connectivity

AWS introduces a preview of Interconnect - last mile with Equinix, offering simplified, secure, and resilient private connections to AWS, featuring MACsec encryption and high availability.

Published November 4, 20264 min readCloud Platforms

Confirmed facts

AWS Interconnect - last mile is now available in preview with Equinix, enabling users to connect their infrastructure across Equinix's global network of 282 data centers to AWS. This service provides managed, private, and resilient connections to AWS, eliminating the need for customers to order cross-connects or configure routers.

Setup is performed via the AWS Management Console, where users select an AWS Region, bandwidth speed, a Direct Connect gateway, and their Equinix Fabric One project ID. AWS then generates an activation key, which is entered into the Equinix Fabric One portal to finalize the connection. Connections can also be initiated from the Equinix Fabric One portal.

AWS and Equinix pre-provision quad-redundant capacity, distributed across two physical locations and four distinct links. This setup includes pre-configured BGP peering, VLANs, and ASNs. The service comes with a 99.99% availability SLA.

Traffic traversing between AWS and Equinix edge devices is encrypted by default using MACsec (Media Access Control Security).

During the preview phase, 1 Gbps Interconnect - last mile connections are available at no charge. These connections are offered to the US West (N. California) Region through the San Jose metro and to the US East (N. Virginia) Region through the Northern Virginia metro.

Upon general availability, the service will support bandwidth scaling from 1 Gbps up to 100 Gbps. Connections can be created using the AWS Management Console, the AWS Command Line Interface (CLI), or the AWS API. An open API package for partner integration is available on GitHub, and comprehensive documentation is provided for AWS Interconnect - last mile.

The announcement was made on November 4, 2026.

Technical analysis

Establishing secure, high-performance, and resilient hybrid cloud connectivity has historically presented significant engineering challenges. Traditional approaches often involve complex manual processes for ordering physical cross-connects, configuring network devices, and managing routing protocols. These tasks demand specialized networking expertise, introduce potential for human error, and can lead to extended provisioning times. The AWS Interconnect - last mile preview with Equinix directly addresses these operational complexities by offering a managed service that abstracts away much of the underlying physical and logical network configuration.

The service's core value proposition for software engineers and network architects lies in its operational simplification. By allowing connection setup through the AWS Management Console or Equinix Fabric One portal, and automatically configuring BGP peering, VLANs, and ASNs, the service significantly reduces the manual effort and specialized knowledge required. This shift from a hardware-centric, manual provisioning model to a software-defined, API-driven approach aligns with modern cloud engineering principles. Engineers can provision private connections with a few clicks, offloading the burden of physical infrastructure setup and complex network configuration to AWS and Equinix. This automation can accelerate the deployment of hybrid cloud architectures, allowing development teams to focus on application logic rather than network plumbing.

Security is a critical concern for hybrid cloud deployments, particularly for sensitive data traversing between on-premises environments and the cloud. The inclusion of MACsec encryption by default for traffic between AWS and Equinix edge devices is a notable enhancement. MACsec operates at Layer 2 (the data link layer) of the OSI model, providing hop-by-hop encryption and data integrity checks. This physical layer encryption offers a robust security baseline, protecting data in transit from eavesdropping and tampering before it reaches higher-layer encryption mechanisms. For organizations with stringent compliance requirements or those handling highly confidential information, this default MACsec encryption provides an additional layer of assurance without requiring explicit configuration by the user, simplifying the security posture of the hybrid connection.

The design for resilience and availability is another key technical aspect. The pre-provisioned quad-redundant capacity, spread across two locations and four separate links, is engineered to minimize single points of failure. This architecture, combined with the 99.99% availability SLA, provides a foundation for highly available applications that span on-premises and AWS environments. For mission-critical workloads, this level of redundancy is essential, ensuring continuous operation even in the event of component failures or localized outages. The automated setup of this complex redundancy further reduces engineering overhead, as teams do not need to design, implement, and validate such a resilient network topology themselves.

The availability of an open API package on GitHub for partner integration indicates a strategic move towards fostering an ecosystem around AWS Interconnect - last mile. This allows third-party vendors and service providers to build integrations, potentially extending the reach and capabilities of the service. For developers, the ability to create connections using the AWS CLI or API means that provisioning can be integrated into existing infrastructure-as-code workflows and automated deployment pipelines. This programmatic control is fundamental for scalable and repeatable hybrid cloud deployments, enabling consistent configuration and reducing manual intervention.

During the preview, the service is limited to 1 Gbps connections and specific US regions (N. California and N. Virginia). While this initial bandwidth and regional scope are suitable for evaluation and initial deployments, the confirmed plan to scale bandwidth from 1 Gbps to 100 Gbps upon general availability addresses the needs of high-throughput workloads and larger enterprises. The no-charge preview period offers a practical opportunity for engineering teams to evaluate the service's performance, integration capabilities, and operational benefits within their existing hybrid cloud setups before committing to broader adoption. The documentation for AWS Interconnect - last mile will be a critical resource for engineers to understand the detailed operational procedures, integration patterns, and best practices for leveraging this new connectivity option.
