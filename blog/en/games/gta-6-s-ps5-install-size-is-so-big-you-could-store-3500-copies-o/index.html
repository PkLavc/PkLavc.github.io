GTA 6's PS5 install size is so big you could store 3500 copies of Balatro inside

That's a lot of space to ask for in the midst of the memory crisis.

Published October 28, 20261 min readGTA & Rockstar
Image source: PC Gamer

Confirmed facts

PC Gamer has reported on the substantial install size for Grand Theft Auto 6 on PlayStation 5. According to the publication, the upcoming title is so large that its storage footprint could accommodate approximately 3500 copies of the popular deck-builder game, Balatro (PC Gamer). This report highlights a significant demand for console storage space from the highly anticipated Rockstar Games release.

Technical analysis

The reported install size for GTA 6 presents notable implications for PlayStation 5 owners, particularly in the context of current console storage capacities. PC Gamer notes that this considerable demand for space comes amidst a perceived "memory crisis" for gamers, where internal console storage is often a premium commodity. Such a large file size could necessitate players managing their existing game libraries or considering external storage solutions to accommodate GTA 6 (PC Gamer).
