Autotrader

Sistema autônomo de pesquisa de mercado que transforma previsões do Kronos-base em uma carteira simulada com limites rígidos, roda sozinho pelo GitHub Actions e expõe cada decisão em um dashboard público.

Abrir dashboard ao vivo Ver no GitHub

Pesquisa autônoma de carteira, não uma demonstração estática

O Autotrader foi criado para responder uma pergunta de engenharia: o que acontece quando um modelo fundacional financeiro pode analisar sozinho um universo fixo de ativos líquidos, ranquear suas previsões, montar uma carteira sob limites de risco e repetir o processo automaticamente ao longo do tempo?

20market assets scanned
5maximum positions
18%max weight per asset
10%minimum cash buffer

Pipeline de decisão

Cada execução agendada baixa dados diários atualizados, gera uma previsão de cinco pregões com Kronos para cada ativo, ranqueia os retornos esperados e rebalanceia uma conta simulada preservando limites de caixa e concentração.

1. Market dataDaily OHLCV history
2. Kronos-base5-session forecast
3. RankingExpected-return score
4. PortfolioRisk-constrained targets
5. RecordTrades + equity history

Arquitetura e proteções

O projeto separa propositalmente a inferência do modelo das permissões de escrita do repositório. Atualizações do Kronos são fixadas e testadas antes de serem adotadas, enquanto o estado da carteira só é persistido depois de uma simulação concluída com sucesso.

Kronos-base102.3M-parameter financial foundation model used as the forecasting engine.
Python + PyTorchCPU inference, market-data processing, ranking, portfolio construction and simulation.
GitHub ActionsScheduled execution, tests, state persistence and autonomous operation.
Safe upstream syncNew Kronos revisions are adopted only after regression and compatibility tests pass.
Public dashboardEquity curve, bullish/bearish forecast bars, allocation and complete execution log.
Paper executionSimulated fills include slippage and preserve a reproducible history before any live-broker integration.

Experimento público

O dashboard mantém o experimento observável: valor da carteira ao longo do tempo, previsões positivas e negativas do modelo, alocação atual e uma tabela cronológica de compras e vendas simuladas.

Autotrader currently uses simulated capital. The live dashboard is a research record, not financial advice and not evidence of future returns.
