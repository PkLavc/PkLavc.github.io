Omnichannel

Omnichannel es una plataforma autoalojada de atención que conecta Chatwoot con un gateway de agentes especialistas de IA. Identidad, prompts, conocimiento RAG, conversaciones, contactos, tarjetas de atención e integraciones comerciales permanecen aislados por empresa.

CanalesBandejas de WhatsApp, Instagram, Facebook, sitio web y API mediante Chatwoot
OrquestaciónCoordinador y agentes especialistas para Comercial, Soporte y Posventa
ConocimientoDocumentos RAG editables, reglas, respuestas rápidas y conversaciones históricas
PersistenciaPostgreSQL y una carpeta separada y portátil de datos privados
OperaciónTransferencia humana, contexto del cliente, tarjetas y trazas de auditoría
PublicaciónDocker Compose con una capa estable de acceso mediante Cloudflare

Arquitectura del sistema

La capa pública de acceso permanece estable mientras los servicios operativos pueden moverse entre equipos autorizados. El gateway identifica empresa y canal, consulta únicamente el contexto de ese tenant, delega al especialista adecuado y devuelve la respuesta mediante Chatwoot.

Canal del cliente → Chatwoot → Gateway de IA → Coordinador → Agente especialista
RAG y reglas de la empresa → Contexto del cliente y servicio → Respuesta o transferencia humana

Módulos principales

MóduloFinalidad

AdministraciónEmpresas, canales, proveedores, prompts, conocimiento, tarjetas y revisión del aprendizaje.
Carpeta de datos privadosConfiguración, exportaciones, importaciones, conversaciones y estado portátil fuera del repositorio público.
Acceso en la nubeDirecciones estables que informan disponibilidad sin exponer instrucciones internas de desarrollo.

Aislamiento y portabilidad

  • El repositorio público contiene el sistema reutilizable, sin identidad de empresa preconfigurada.
  • Cada tenant tiene sus propios prompts, reglas, canales, RAG, conversaciones, contactos y tarjetas.
  • Las credenciales de proveedores pueden ser globales, con un alcance de empresas explícito.
  • La carpeta privada se puede exportar, copiar y restaurar independientemente del código de la aplicación.

Modelo operativo

La stack se inicia únicamente mediante una acción explícita del operador. Mientras el backend está en línea, los usuarios autorizados acceden a la dirección web estable; cuando no está disponible, la página pública muestra solo un estado neutral del servicio. No existe inicio automático en Windows.
